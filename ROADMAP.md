# Roadmap

These are the areas I'm currently planning to work on next. Priorities may change based on user feedback and project needs.

* FOCUS specification support
* Multi-cluster cost aggregation
* Cost trend comparison across time periods
* Agentic optimization workflows (in development)
  * Evidence-backed workload rightsizing
  * Reliability guardrails and human-approved GitOps changes
  * Post-deployment verification and savings reconciliation

These workflows will be opt-in. Burn's core CLI will remain agentless and read-only.

Feedback and feature requests are welcome. Please open an issue on [GitHub](https://github.com/tanrikuluozlem/burn/issues).
